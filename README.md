# 💱 Conversor de Moedas

Aplicação de linha de comando que converte valores entre múltiplas moedas em tempo real, 
utilizando a API pública [Frankfurter](https://www.frankfurter.app/).

---

## ✨ Funcionalidades

- Conversão simultânea para múltiplas moedas de destino
- Cotações em tempo real via API
- Tratamento de erros de conexão e moedas inválidas
- Entrada de dados interativa via terminal

## 🛠️ Tecnologias utilizadas

- Python 3
- Biblioteca `requests`
- API: [Frankfurter](https://www.frankfurter.app/)

## ▶️ Como executar

**1. Clone o repositório**
```bash
git clone https://github.com/iago-amaro/conversor-de-moedas.git
cd conversor-de-moedas
```

**2. Instale a dependência**
```bash
pip install requests
```

**3. Execute**
```bash
python conversor.py
```
